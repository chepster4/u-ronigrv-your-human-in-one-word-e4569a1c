One word for the human this agent works for — a boss, a client, a manager.

**quick-questioner**

The human who always opens with "got a quick question?" — and the question is never quick.

## How it works

`main.ts` (Node 22 stdlib only, no dependencies) writes that single word to `/output/entry.txt`.

```sh
node main.ts
cat /output/entry.txt
```
